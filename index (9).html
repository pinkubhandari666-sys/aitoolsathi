How to edit text in a JPG?

  1. Upload a JPG/JPEG image.
  2. Select Detect text to find words using OCR.
  3. Select a detected word box and cover it, or use Manual cover mode to drag over an area.
  4. Type replacement text, choose font, size and colour, then add it and drag it into place.
  5. Download the edited image as JPG.

Important limitations

JPG text is part of the image pixels, not a separate editable text layer. This tool covers selected areas and adds new text; it does not perform AI inpainting or perfectly restore detailed backgrounds. OCR is best-effort and requires internet access to load Tesseract.js and language data.
